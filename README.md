# 🎬 Jio Hotstar Clone

A modern and responsive **Jio Hotstar-inspired streaming platform UI** built using **HTML and CSS**.  
This project replicates the layout and design of a real OTT platform with multiple pages and clean UI sections.

---

## 🚀 Live Demo

🔗 https://mannpatel108585-jiohotstar-clone.netlify.app/  

---

## 📌 Project Overview

This project is a **frontend clone of Jio Hotstar**, designed to showcase:

- 🎨 Clean UI/UX design
- 📱 Responsive layout
- 🎬 OTT platform structure
- 🔐 Basic login page UI
- 📂 Multi-page navigation system

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- VS Code

## ⚙️ How to Run the Project

1. Clone the repository:
```
git clone https://github.com/mann2007-ptl/diwali_assgn.git
```

2. Open the folder:
```
cd diwali_assgn
```

3. Open index.html in browser or use Live Server.
